# Project Structure (GameWorks OAK)

## 0. ポータル固有のメタデータ例外
GameWorks OAK はポータルサイトおよび共通ライブラリ提供元であり、ゲームプロジェクトカードとして表示される対象ではありません。
そのため、このリポジトリでは `public/data/project_info.json` は必須ではありません。
ポータルに表示する各ゲームのメタデータは、`public/data/project_list.json` と `public/data/projects/*.json` で管理します。

## 1. 特殊構成の意図
このリポジトリは、GameWorks OAK のポータルサイトであると同時に、全プロジェクトが利用する「共通ライブラリ」を提供する役割を持ちます。そのため、共通プロジェクト構造をベースにしつつ、以下の固有構成を持ちます。

## 2. 固有のディレクトリ
- docs/common/: 全プロジェクトで共有される規約・ガイドラインを格納します。
- docs/portal/: このポータルリポジトリ固有の仕様書などを格納します。
- docs/planning/: 開発タスク（バックログ）や一時的な計画書を格納します。
- lib/: 他のプロジェクトから直接参照される「共通ライブラリ」のソースを格納します。
    - styles/: 共通 CSS。
    - scripts/: 共通 JS モジュール。
    - assets/: 共通アセット。
- public/data/: ポータルサイトに表示するための各プロジェクトのメタデータや更新履歴を管理します。

## 3. ポータルサイトの実装
ポータルサイト本体（index.html, main.js, index.css）はルート直下に配置し、lib/ 配下の共通ライブラリを利用する際の実装サンプルとしての役割も兼ねます。
