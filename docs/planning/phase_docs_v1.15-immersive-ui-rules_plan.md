# 没入を守る共通表示・操作ルールの整備計画

## 目的

プレイヤーがゲームの世界観に入り込めるよう、ブラウザ標準の表示・操作によって現実へ引き戻されることを防ぐ。個別の禁止事項だけでなく、未列挙の表示・操作にも適用できる共通原則を定める。

## 合意した開発条件

- 対象領域: 共通仕様・共有ドキュメント。
- 予定バージョン: 1.15.0。実装開始時に package.json と package-lock.json を更新する。
- ブランチ名: docs/v1.15-immersive-ui-rules。
- ゲーム画面を対象とする。ポータルへの同じ禁止事項の適用は今回決定しない。

## スコープ

- 共通理念に、世界観への没入を守る方針を追記する。
- PC・モバイルを通したゲーム画面の共通表示・操作ルールを文書化し、関連文書から参照できるようにする。
- 既存のモバイル向けルールとの責務を整理し、重複や矛盾を避ける。
- 準拠チェックリストへ共通原則・具体例・例外の確認項目を追加する。

### 上位原則

プレイヤーの没入を守るため、ゲーム側で制御できる表示・操作には、世界観に合わないブラウザ標準UI・標準動作を使用しない。必要な機能は、世界観に合うゲーム内UI・操作として提供する。

ただし、文字入力などゲームに必要な操作を損なう抑止は行わない。例外は、必要な場面と対象に限定する。

個別項目は上位原則の具体例であり、禁止対象を列挙項目だけに限定しない。ブラウザのアドレスバーなどゲーム側で制御できない部分は対象外とする。

### 明記する禁止事項

- 標準のスクロールバー外観。必要なスクロールは、世界観に合う外観と操作性を提供する。
- title 属性による標準ツールチップ。必要な説明はゲーム内UIで提供する。
- キーボード入力を必須としないゲームでの、Tab・Shift+Tabによる不要なフォーカス移動。
- ブラウザ標準のフォーカス枠。必要なフォーカス表示は世界観に合う表現を用意する。
- alert・confirm・prompt による標準ダイアログ。通知・確認・入力はゲーム内UIで提供する。
- 右クリック・長押しによる標準コンテキストメニュー。
- 意図しない文字選択・画像ドラッグ・選択メニュー。
- フォームのブラウザ標準エラー表示。検証とエラー通知はゲーム内UIで提供する。

### 例外と操作性

- 文字入力、IME、必要な選択・コピー・貼り付けなど、ゲームに必要な入力操作を保護する。
- キーボード操作が必要な場面では、その操作性と必要なフォーカスの認識を維持する。
- フォーカス枠の非表示だけで対応を完了させず、フォーカス移動と表示を分けて規定する。
- 全画面・全イベントへの一律抑止で必要な操作を壊さないよう、例外の必要性と適用範囲を各ゲーム仕様で判断できる記述にする。

## 対象外

- ゲーム・ポータル・共通ライブラリの動作、HTML、CSS、JavaScriptの変更。
- 兄弟ゲームリポジトリの編集。
- ブラウザ側で制御できない表示・操作の強制的な抑止。
- 今回の原則と無関係な既存ルールの改定。

## 完了条件

- 理念、共通表示・操作ルール、モバイル規定、チェックリストの参照関係が整合している。
- 未列挙の標準UIにも上位原則を適用できる。
- 上記の禁止事項と必要な入力の例外が明記され、実装・レビューで判断できる。
- ゲーム側で制御できる範囲とゲーム画面への適用が明確である。
- 設定バージョンを1.15.0に更新し、全テスト・本番ビルドの結果を実装報告に記録する。

## 実装・検証方針

- docs/common/01.philosophy.md、02.doc_guide.md、06.css_design_rules.md、07.mobile_browser_rules.md、99.compliance_checklist.mdを照合する。
- 横断的な表示・操作ルールは独立した共通文書に集約し、理念・関連規定から参照する。ファイル名は既存の番号・文書構成と整合させる。
- 通常文書には変更履歴を混ぜず、目的と現在の規定を書く。利用者向けupdate_history.jsonへの記載要否は、共通構成の記載対象に従う。
- リンク、禁止事項の網羅性、例外と既存規定の矛盾を確認する。文書だけの変更を理由に全テスト・ビルドを省略しない。
- npm test と npm run build を実行する。失敗は原因を調査し、対応または範囲外とする根拠を実装報告へ記録する。
- 動作変更はないため、ゲーム操作のオーナー検証を機械的に要求しない。規定の解釈に未解決の判断が生じた場合は、終了草案前に確認する。
