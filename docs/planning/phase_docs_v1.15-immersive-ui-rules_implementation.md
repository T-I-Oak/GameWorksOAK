### 全テスト

- `npm test`: 初回は5スイートともテスト収集前に失敗した。一時キャッシュのrenameがサンドボックスのTEMP配下でEPERMとなり、テストは実行されなかった。
- 原因調査: インストール済みVitestが `node:os` の `tmpdir()` 配下に一時キャッシュを作ることと、エラーの対象パスを照合した。
- 再実行コマンド（PowerShell）:

  ```powershell
  $env:TEMP = Join-Path (Get-Location) 'tmp_vitest'
  $env:TMP = $env:TEMP
  New-Item -ItemType Directory -Path $env:TEMP -Force | Out-Null
  npm test
  ```

- 結果: 5ファイル、63テストすべて成功。実行プロセスの一時領域だけを変更し、テスト・依存関係・リポジトリ設定は変更していない。一時ディレクトリは検証後に削除した。

### 本番ビルド

- `npm run build`: 成功。Viteによる11モジュールのビルドと、postbuildの `src/lib` から `dist/lib` へのコピーが完了した。
