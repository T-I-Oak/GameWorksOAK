# v1.16 ゲーム内UIの絵文字と特殊フォントの規定

## 開発スコープ

- 予定バージョンは v1.16.0。開発ブランチは `docs/v1.16-immersive-typography`。
- ゲーム画面の共通表示・操作ルールに、ゲーム側が用意するボタン、メニュー、メッセージ、装飾で、OSやブラウザの絵文字フォントに依存するUnicode絵文字の使用を禁止する規定を追加する。必要なアイコンにはゲームに同梱した画像などを使う。プレイヤーの入力文字はこの禁止の対象外とする。
- 世界観や操作上の意味を特定の字形に頼る特殊フォントは、配布可能なものをゲームのアセットとして同梱し、そのファイルを読み込む。読み込みに失敗した場合やフォントに字形が収録されていない場合に備え、代替フォントを指定する。
- 準拠チェックリストに、絵文字の使用、特殊フォントの同梱・読み込み、代替表示の確認項目を追加する。

## 対象外

- ポータルや既存ゲームへの適用、実際のフォントやアイコン素材の追加。
- 文字一覧の作成、字形の全件照合、ゲーム実行時のアサーションや起動時チェック。

## 実装・検証方針

- `docs/common/06.immersive_ui_rules.md` と `docs/common/99.compliance_checklist.md` に同じ適用範囲と確認方法を記載する。
- ゲーム側で特殊フォントを使う場合の確認は、公開前の開発検証で行う。対応するPC・モバイルのブラウザで代表画面を確認し、同梱フォントが読み込まれること、通常表示と代替表示のどちらでも文言が読めて操作に支障がないことを確かめる。
- 実装開始時にバージョン設定を v1.16.0 に更新し、利用者向け改版履歴には「内部改善」を記載する。

## 完了条件

- 絵文字の禁止範囲、特殊フォントの同梱・読み込み、代替表示、公開前の確認方法が共通仕様とチェックリストで一致する。
- 文書の参照先と差分を確認し、`npm test` と `npm run build` が通る。
