## 旧規定との競合解消
- コミット・タスクごとのPatch更新と文書のみ更新不要を、実装開始・修正着手単位へ置換。
- dev_計画書をphase_成果物へ置換し、既存成果物の移行と旧引継ぎ書削除を規定。
- 1ファイル個別コミット必須を廃止し、承認済みフェーズ単位の変更一式保存へ統一。
- 実装済み項目の一律オーナー検証移動を廃止し、オーナーの明示保留だけに限定。
- 共通部担当による公開確認必須を、ゲーム担当のコマンド判定へ置換。
- 対象外のデータ形式、ライブラリ説明、コーディング・CSS・モバイル規定とテスト方針は維持。
