# Common Library Overview

## 概要
GameWorks OAK Common Library は、ポータルサイトおよび各ゲームプロジェクトで共通して使用するロジックを提供する JavaScript ライブラリです。

## 提供モジュール一覧
- [Env Utility](./library/env_utility.md): 環境情報・バージョン取得
- [Fetch Utility](./library/fetch_utility.md): 共通通信ラッパー
- [DataManager](./library/data_manager.md): 標準データ構造へのアクセス抽象化

## 導入方法
各プロジェクトから以下のパス形式でインポートして使用します。

```javascript
// 例
import { ... } from '../common/utils/fetch.js';
```
