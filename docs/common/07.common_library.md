# Common Library Overview

## 概要
GameWorks OAK Common Library は、ポータルサイトおよび各ゲームプロジェクトで共通して使用するロジックを提供する JavaScript ライブラリです。

## 提供モジュール一覧
- [Env Utility](./library/env_utility.md): 環境情報・バージョン取得
- [Fetch Utility](./library/fetch_utility.md): 共通通信ラッパー
- [DataManager](./library/data_manager.md): ゲーム個別データの名前空間分離と永続化、自動マイグレーション
- [Multi-Language (i18n)](./library/i18n.md): ゲーム間共有可能な言語設定と JSON の自動多言語展開
- [TutorialManager](./library/tutorial_manager.md): ポータブルなチュートリアル進行制御

## 導入方法
本ライブラリは、各プロジェクトにファイルをコピーして使用することはせず、GameWorks OAK ポータルが提供する共通リソースを直接参照して使用してください。これにより、ロジックの修正や仕様変更がすべてのプロジェクトに即座に反映される状態を維持します。

### 直接インポートの利用方法
ES Modules のインポート機能を使用して、ポータルの `lib/` フォルダ配下のファイルを直接指定します。これにより、すべてのプロジェクトで常に最新かつ同一のロジックが使用されることが保証されます。

```javascript
// 例: DataManager を使用する場合
import { DataManager } from 'https://t-i-oak.github.io/GameWorksOAK/lib/core/dataManager.js';

// 例: i18n 多言語機能を使用する場合
import { expandLanguageResource } from 'https://t-i-oak.github.io/GameWorksOAK/lib/core/i18n.js';

// 例: Fetch Utility を使用する場合
import { commonFetch } from 'https://t-i-oak.github.io/GameWorksOAK/lib/utils/fetch.js';

// 例: TutorialManager を使用する場合
import { TutorialManager } from 'https://t-i-oak.github.io/GameWorksOAK/lib/core/tutorialManager.js';
```
