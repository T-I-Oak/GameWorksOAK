# Common Library Overview

## 概要
GameWorks OAK Common Library は、ポータルサイトおよび各ゲームプロジェクトで共通して使用するロジックを提供する JavaScript ライブラリです。

## 提供モジュール一覧
- [Env Utility](./library/env_utility.md): 環境情報・バージョン取得
- [Fetch Utility](./library/fetch_utility.md): 共通通信ラッパー
- [DataManager](./library/data_manager.md): ゲーム個別データの名前空間分離と永続化、自動マイグレーション
- [Multi-Language (i18n)](./library/i18n.md): ゲーム間共有可能な言語設定と JSON の自動多言語展開
- [TutorialManager](./library/tutorial_manager.md): ポータブルなチュートリアル進行制御

## 導入方法
本ライブラリは、各ゲームプロジェクトのソースからローカルの GameWorks OAK リポジトリにある `src/lib/` を直接 import して使用します。
ゲームの build 時には、その時点で参照されている共通ライブラリがゲーム側 bundle に静的に取り込まれます。

### ローカル検証時
ローカル環境では、各ゲームリポジトリの隣に配置された GameWorks OAK リポジトリを参照します。
これにより、共通ライブラリの修正を各ゲームで確認できます。

```javascript
// 例: DataManager を使用する場合
import { DataManager } from '../../../GameWorksOAK/src/lib/core/dataManager.js';

// 例: i18n 多言語機能を使用する場合
import { expandLanguageResource } from '../../../GameWorksOAK/src/lib/core/i18n.js';

// 例: Fetch Utility を使用する場合
import { commonFetch } from '../../../GameWorksOAK/src/lib/utils/fetch.js';

// 例: TutorialManager を使用する場合
import { TutorialManager } from '../../../GameWorksOAK/src/lib/core/tutorialManager.js';
```

相対パスの階層数は、import 元ファイルの位置に合わせて調整してください。

### リモート build 時
GitHub Actions などのリモート build では、ゲームリポジトリとは別に GameWorks OAK リポジトリを checkout し、上記の相対 import が解決できる位置へリンクします。

このとき bundle に取り込まれるのは、ローカル作業ツリーではなく、公開済み（remote に push 済み）の GameWorks OAK リポジトリ上の `src/lib/` です。
そのため、共通ライブラリの修正をゲームの公開版へ反映する場合は、先に GameWorks OAK 側の変更を `master` へ merge / push してから、対象ゲームを build / deploy してください。

### 公開後の挙動
公開済みゲームは、GameWorks OAK の公開 `lib/` を実行時に動的 import しません。
公開済みゲームで使用される共通ライブラリは、そのゲームを build した時点で bundle に静的に取り込まれたものです。

これにより、GameWorks OAK 側の更新だけで公開済みゲームの挙動が突然変わることを防ぎます。
