# Multi-Language (i18n) Library Specification

## 役割
GameWorks OAK ポータルおよび各ゲームアプリ間で「言語設定」をシームレスに同期・共有し、ローカルやリモートの JSON リソースを多言語に自動展開する機能を提供します。

---

## 共有言語設定
言語設定は、個別ゲームID（`gameId`）の領域から独立したドメイン共通の保存キー（`'gameworks_portal_lang'`) で `localStorage` に直接保存されます。
これにより、ポータルサイトでの言語選択（日本語 ⇄ English）が、全ゲームアプリに対してもシームレスかつ即座に反映・共有されます。

---

## サポートする言語コードの規格 (規格マスター)

他のゲームアプリやポータルで、言語識別用のキー（キー名）が混在（例: `"jp"` と `"ja"` の混在）してデータ連携が破壊されることを防ぐため、GameWorks OAK プロジェクト群における多言語対応の言語コードは以下の **ISO 639-1** 規格に厳格に準拠して定義します。

> [!WARNING]
> 国名コード（例: `"jp"`）を言語コードとして使用することは**厳禁**とします。必ず以下の「言語コード」を使用してください。

| 言語コード (Key) | 対象言語 | 表示名 (推奨) | 備考 |
| :--- | :--- | :--- | :--- |
| **`ja`** | 日本語 (Japanese) | `日本語` | `"jp"` は使用禁止。 |
| **`en`** | 英語 (English) | `English` | デフォルトのフォールバック言語。 |
| **`zh`** | 中国語 (Chinese) | `中文` | 将来の拡張用。必要に応じて `"zh-cn"`, `"zh-tw"` と記述。 |
| **`ko`** | 韓国語 (Korean) | `한국어` | 将来の拡張用。 |

各ゲームアプリが提供する言語選択UI（プルダウンなど）は、それぞれのゲームが対応している言語リソースの状況に合わせて、上記テーブルのコードを用いて独自に構築してください。
ライブラリレベルで一元的なリストを提供しないことにより、**「ゲームで対応していない言語がプルダウンに表示され、ユーザーが立ち往生する現象」を完全に回避**しつつ、ドメイン全体での言語設定キーの整合性を完璧に維持します。

---

## JSON データ仕様 (`lang-store`)

言語ごとの動的テキストは、JSON オブジェクトの中に `"lang-store"` というキーを持つオブジェクトを定義して表現します。
```json
{
  "title": {
    "lang-store": {
      "ja": "こんにちは",
      "en": "Hello"
    }
  },
  "score": 100
}
```

*   **展開ルール**:
    *   システムが `"lang-store"` オブジェクトを走査した際、現在の言語コード（例: `"ja"`) に対応する値にオブジェクト自体を置換します。
    *   現在の言語コードに対応する値が定義されていない場合は、デフォルトの **`"en"`** の値へとフォールバックします。
    *   上記のデータ構造は、多言語展開後は以下のようにシンプルなプレーンオブジェクトへと変換されます：
    ```json
    // 日本語設定（ja）の場合
    {
      "title": "こんにちは",
      "score": 100
    }
    ```

## API

### `getLanguage(): string`
*   **詳細**: 現在の言語コード（例: `'en'`, `'ja'`) を取得します。デフォルトは `'en'` です。

### `setLanguage(lang: string): void`
*   **詳細**: `localStorage`（共通キー）に指定された言語コードを保存し、ドメイン全体に言語設定を反映します。

### `expandLanguageResource(jsonObj: any): any`
*   **詳細**: 引数として渡された JSON オブジェクトを再帰的に走査し、内部の `"lang-store"` 要素をすべて現在の言語設定に従って置換した新しいオブジェクトを返します。
*   **深さの制限**: 探索の深さは **`10`** に固定されており、10 を超えるネストや循環参照が発生した場合はエラー（例外）をスローして処理を安全に終了します。

### `loadJsonWithL10n(url: string): Promise<object>`
*   **詳細**: 指定された外部の JSON ファイルを非同期（`fetch`）でロードし、多言語展開したオブジェクトを Promise として返します。

---

## 使用例

### 1. 同期的なローカルリソース展開 (静的 `import` された JSON の多言語化)
```javascript
import { expandLanguageResource } from 'https://t-i-oak.github.io/GameWorksOAK/lib/core/i18n.js';
import myLocalDataRaw from './my_data.json';

// メモリ上のオブジェクトを同期的に多言語展開
const data = expandLanguageResource(myLocalDataRaw);
console.log(data.title); // 日本語設定なら「こんにちは」が出力
```

### 2. 非同期な外部リソース展開 (動的なフェッチによる多言語化)
```javascript
import { loadJsonWithL10n } from 'https://t-i-oak.github.io/GameWorksOAK/lib/core/i18n.js';

// 外部ファイルをフェッチして、自動的に多言語化されたオブジェクトを取得
loadJsonWithL10n('data/game_items.json').then(items => {
    console.log(items[0].name);
});
```
