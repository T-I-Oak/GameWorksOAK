# ゲーム画面の共通表示・操作ルール

## 1. 目的と適用範囲

プレイヤーがゲームの世界観に入り込めるよう、表示と操作の一貫性を守る。
PC・モバイルを通して、ゲーム画面と、その説明・設定・入力・確認などのゲーム内UIに適用する。
ポータルに同じ禁止事項を適用するかどうかは本書では定めない。

ゲーム側で制御できる表示・操作には、世界観に合わないブラウザ標準UI・標準動作を使用しない。
必要な機能は、世界観に合うゲーム内UI・操作として提供する。
第2節はこの原則の具体例であり、列挙されていない表示・操作にも同じ原則を適用する。
アドレスバーなど、ゲーム側で制御できないブラウザの表示・操作は対象外とする。

## 2. 標準UI・標準動作の禁止事項

以下をゲーム画面に出さない。必要な入力操作については第3節の例外を適用する。

| 対象 | 規定と必要な代替手段 |
| --- | --- |
| 標準のスクロールバー外観 | 必要なスクロールは、世界観に合う外観と操作性を提供する。バーを隠すだけで必要な内容へ到達できなくしてはならない。 |
| `title` 属性による標準ツールチップ | 必要な説明はゲーム内UIで提供し、対応する入力方法で参照できるようにする。 |
| Tab・Shift+Tabによる不要なフォーカス移動 | キーボード入力を必須としないゲームでは、ゲーム操作に不要な移動を発生させない。必要な入力場面の移動は第3節に従う。 |
| ブラウザ標準のフォーカス枠 | 必要なフォーカス表示は世界観に合う表現で提供する。枠の非表示だけでは不要なフォーカス移動を抑止したことにならない。 |
| `alert`・`confirm`・`prompt` による標準ダイアログ | 通知・確認・入力はゲーム内UIで提供する。 |
| 右クリック・長押しによる標準コンテキストメニュー | ゲーム操作領域では抑止し、必要なゲーム内機能はゲーム内UIで提供する。 |
| 意図しない文字選択・画像ドラッグ・選択メニュー | ゲーム操作で発生しないようにする。必要な文字操作は第3節に従う。 |
| フォームのブラウザ標準エラー表示 | 検証とエラー通知をゲーム内UIで提供し、入力の修正・再試行を可能にする。標準表示を抑止するだけで検証を失わせてはならない。 |

## 3. 必要な入力操作の例外

文字入力、IMEによる変換・確定、必要な選択・コピー・貼り付けなど、ゲームに必要な入力操作を保護する。
その操作のために必要な標準メニューや表示は、必要な場面と対象に限定して許可する。
キーボード操作が必要な場面では、必要なフォーカス移動と、現在のフォーカスを認識できる世界観に合う表示を維持する。
キーボード入力を必須としないゲームでも、名前入力など必要な入力場面にはこの例外を適用する。

各ゲーム仕様に、例外が必要な理由、対象画面・要素、許可する操作・表示、適用条件を明記する。
例えば名前入力欄でのIME・選択・貼り付けを保護しつつ、その外側の盤面では意図しない選択や長押しメニューを抑止する。
全画面への `user-select: none` や全イベントへの一律の `preventDefault()` などで、必要な入力、フォーカス移動、内部スクロールを壊してはならない。

## 4. 関連規定と確認

- 視覚表現の実装は[CSS設計ルール](06.css_design_rules.md)に従う。
- viewport、内部スクロール領域、タッチ入力などのモバイル固有の実装は[モバイルブラウザ規定](07.mobile_browser_rules.md)に従う。同文書の抑止例にも第3節の適用範囲を守る。
- [準拠チェックリスト](99.compliance_checklist.md)を用い、PCの右クリック・キーボード操作と、モバイルの長押し・タッチ操作の双方で、禁止事項と必要な入力の維持を確認する。
- 未列挙の標準UIにも第1節を適用し、ゲーム側で制御できるか、代替機能が使えるか、例外が必要な入力範囲に限られるかを確認する。

## 5. 絵文字と特殊フォント

ゲーム側が用意するボタン、メニュー、メッセージ、装飾などには、OSやブラウザの絵文字フォントに依存するUnicode絵文字を使用しない。アイコンが必要な場合は、ゲームに同梱した画像などを使用する。プレイヤーが入力した文字は、この禁止の対象外とする。

世界観や操作上の意味を特定の字形に頼る特殊フォントを使用する場合は、配布可能なフォントをゲームのアセットとして同梱し、同梱したファイルを読み込む。フォントを読み込めない場合や表示する文字の字形が収録されていない場合に備え、代替フォントを指定する。

公開前の開発検証では、対応するPC・モバイルのブラウザで代表的な画面を確認する。同梱フォントが読み込まれることと、通常表示でも代替表示でも文言が読めて操作に支障がないことを確認する。文字一覧の作成や字形の全件照合は不要とし、この確認のためにゲーム実行時のアサーションや起動時チェックを追加しない。
